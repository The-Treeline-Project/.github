## Projects

Below here is a catalogue of our projects.

<h3>
  <a href="https://github.com/The-Treeline-Project/Silva-Releases">
    <img
      src="https://github.com/The-Treeline-Project/Silva-Releases/blob/main/icons/silva.svg?raw=true"
      alt="Silva Logo"
      width="42"
      align="absmiddle"
    >
    Silva
  </a>
</h3>

Silva is a automated Pokémon GO "Dumper", it checks for new available versions on the Google Play Store every 30 minutes (this can be delayed if the request(s) are being blocked), if it finds a new version (it checks for both releases and unreleased versions), it downloads it, dumps some stuff from it and creates a GitHub Release in a specific format.

It automatically dumps Protobuf files (using a custom-written dumper), dumps IL2CPP (using [IL2CPPDumper-Linux](https://github.com/AndnixSH/Il2CppDumper)) and uploads certain files that may be useful for reverse engineering/running specific tools.

For obvious reasons the project itself is not open-source.s

This is not affiliated to other existing solutions (like ProtoMines), all the code is custom-built.
